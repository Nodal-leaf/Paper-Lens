Project rules:

1. Prefer minimal implementations.
2. Do not create files unless necessary.
3. Do not create abstractions without explicit justification.
4. Do not refactor unrelated code.
5. Never modify existing files unless requested.
6. Prefer simple functions over classes.
7. Reuse existing dependencies.
8. Before coding, inspect the repository.
9. State which files will be changed before making changes.
10. After coding, summarize every file changed and why.
